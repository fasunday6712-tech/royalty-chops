FREE HOSTING WITH GITHUB PAGES:
1. Create/sign into GitHub.
2. Create a new PUBLIC repository named royalty-chops (or another name you prefer).
3. Upload index.html to the repository root using Add file > Upload files.
4. Commit the changes.
5. Open Settings > Pages.
6. Under Build and deployment, choose Deploy from a branch.
7. Select branch main and folder /(root), then Save.
8. Wait for deployment and open the URL shown in Settings > Pages. It will usually look like https://YOUR-USERNAME.github.io/royalty-chops/

The site is static and does not require a backend. GitHub Pages is free for public repositories. Do not put passwords or private information in the public repository.
